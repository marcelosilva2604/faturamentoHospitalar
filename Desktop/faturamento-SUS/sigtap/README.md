# Tabela SIGTAP - Sistema de Gerenciamento da Tabela de Procedimentos SUS

## Sobre
Esta pasta contém informações sobre a tabela SIGTAP oficial do DATASUS, que define os valores de remuneração dos procedimentos do Sistema Único de Saúde (SUS).

## Download Manual Necessário
O download automático da tabela SIGTAP mais recente não está disponível. Para obter os dados atualizados:

1. Acesse: http://sigtap.datasus.gov.br/tabela-unificada/app/download.jsp
2. Selecione a competência desejada (mês/ano)
3. Baixe o arquivo ZIP oficial
4. Extraia os arquivos TXT nesta pasta

## Estrutura da Tabela SIGTAP
A tabela contém informações sobre:
- Códigos de procedimentos médicos
- Valores de remuneração (AIH - Autorização de Internação Hospitalar)
- Especialidades e modalidades de atendimento
- Componentes de custo (serviços hospitalares, profissionais, SADT, etc.)
